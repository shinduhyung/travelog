# Italian style

- Translate from the English. Natural, fluent text as a native travel-guide
  editor would write; restructure sentences freely.
- Short UI labels: concise noun phrases, no sentence-ending punctuation.
- Use the established local name for places, landmarks, people and
  dynasties; otherwise the standard transliteration convention.
- Numbers: local digit grouping and decimal separator conventions; units as
  in the source (m, km).
- Address the user with "tu". Sentence case for titles.
- "~229 million" → "circa 229 milioni"; "$1.2 billion" → "1,2 miliardi di dollari".

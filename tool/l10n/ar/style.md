# Arabic style

- Translate from the English. Natural, fluent text as a native travel-guide
  editor would write; restructure sentences freely.
- Short UI labels: concise noun phrases, no sentence-ending punctuation.
- Use the established local name for places, landmarks, people and
  dynasties; otherwise the standard transliteration convention.
- Numbers: local digit grouping and decimal separator conventions; units as
  in the source (m, km).
- English "billion" is 10^9 and "trillion" is 10^12: use the word your
  language has for that exact value, not its look-alike.
- Modern Standard Arabic. Address the user neutrally. Keep Latin-script brand
  names and acronyms as is.
- Use Western Arabic digits (0-9) as in the source, not Eastern Arabic-Indic digits.
- Text is right-to-left: keep placeholders ({0}) and Latin words in the sequence a reader expects; do not add directional marks.
- "~229 million" → "حوالي 229 مليون"; "$1.2 billion" → "1.2 مليار دولار"; "$1.2 trillion" → "1.2 تريليون دولار".

# Polish style

- Translate from the English. Natural, fluent text as a native travel-guide
  editor would write; restructure sentences freely.
- Short UI labels: concise noun phrases, no sentence-ending punctuation.
- Use the established Polish name for places, landmarks, people and
  dynasties (Wiedeń, Rzym, Karol Wielki); otherwise keep the original name.
- Numbers: space as thousands separator, comma as decimal separator; units
  as in the source (m, km).
- Address the user informally ("Twój", "możesz"), or avoid pronouns by using
  neutral constructions. Sentence case for titles.
- Plurals: when a count comes from a placeholder ({0} cities), the Polish
  noun form depends on the number (1 miasto, 2 miasta, 5 miast). Prefer
  constructions that avoid agreement: "Miasta: {0}", "Odwiedzin: {0}",
  "{0} dni" only when the source is clearly not a count of a noun that
  needs agreement.
- "~229 million" → "ok. 229 mln"; "$1.2 billion" → "1,2 mld dolarów";
  "$1.2 trillion" → "1,2 bln dolarów" (Polish "bilion" is 10^12).
